ONE-TIME SETUP FOR VOTES (the Votes tab in the admin stays empty until this is done; if you already did it, only step 4 is needed again)
 1. Open your Google Apps Script project (the one behind the forms).
 2. Paste all of tools/photo-votes.gs into it (replace the old copy of this file).
 3. Add the first line shown at the top of that file inside doPost(e) and the second inside doGet(e), as the very first line of each function.
 4. Deploy > Manage deployments > pencil > Version: New version > Deploy.
 The script only counts votes between 9 a.m. and 5 p.m. on 13 Nov (Sri Lanka time). To test it earlier, set PHOTO_VOTE_OPENS and PHOTO_VOTE_CLOSES to '' (empty), then put the times back.
GitHub: do NOT put the words "photos batch" in the commit message (vercel.json skips the deploy for those).
